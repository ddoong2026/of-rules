게임 배경에 조사 유물이 식별 가능한 형태로 모두 포함됐다고 판정할 수 없다. 건물만 있고 자료 목록만 텍스트로 제공되는 경우는 '그림에 유물이 포함됨' 요건을 충족하지 못한다. 각 경로의 유물 위치를 확대 화면에서 확인하고 실제 게임 상호작용 위치와 다시 맞춰야 한다.

## 이번 반영과 후속 이미지 수정 기준

- 코드 반영: 출처 쪽수 정리, 다호리 붓의 양끝 털, 덩이쇠의 화폐 기능, 불국사·청해진의 다른 장소 명시, 동예 경계 표현 수정. 검수 표시는 '교과서 본문 대조 완료 · 유물 그림 수정 필요'로 변경.
- 이미지 파일은 이번에 재생성하지 않았으며, 미검증 상태를 해제하지 않았다. 텍스트 수정만으로 위 시각 오류가 해결되지는 않는다.
- 다음 제작은 기존 캐릭터의 얼굴·머리와 몸 비율을 유지하고, 래스터 스프라이트 방식과 확대 탐색을 유지한다. 교과서 사진의 유물 윤곽을 개별 참조하여 수정하고, 임의로 장식하지 않는다.
- 유물 0개인 옥저·동예와 통일 과정은 교과서 지도·사건 자료를 명확히 구분하여 제공한다. 두 개 유물을 임의로 만들어 채우지 않는다.
- 같은 화면에 여러 시기·장소를 넣을 경우 영역을 구분하고 각각 표시한다. 특히 건국 장면과 후대 수막새, 경주의 불국사와 청해진 항구를 한 현장처럼 표현하지 않는다.
- 재생성 후 모든 유물을 실물 사진과 다시 대조하고 확대 식별성·핫스폿 좌표를 확인해야 시각 검수를 완료할 수 있다. 배포는 하지 않는다.
